## Caption and hashtags

Separate Spring contexts keep separate bean registries. ☕

Register alpha in context A and beta in independent context B. A does not gain access to beta just because both contexts live in the same Java application.

Give a fresh child context a parent before refreshing it, and named lookup can check locally, then continue upward. The child can retrieve the parent's shared bean. The parent cannot search down for the child's local bean.

The registries stay separate, and the parent bean is returned by reference.
