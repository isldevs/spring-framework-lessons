## Title

Spring IoC Explained: Who Creates Your Java Objects?

## Description

Who creates and wires your Java objects? See manual construction beside Spring’s IoC container, follow a repository into a service, and watch the application request the service with getBean().

Spring manages the beans you register. It does not create every Java object.

Official Spring references:
