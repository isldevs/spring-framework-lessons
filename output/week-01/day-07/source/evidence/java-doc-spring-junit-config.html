Package org.springframework.test.context.junit.jupiter

Annotation Interface SpringJUnitConfig

@ExtendWith(SpringExtension.class) @ContextConfiguration @Documented @Inherited @Retention(RUNTIME) @Target(TYPE) public @interface SpringJUnitConfig
@SpringJUnitConfig is a composed annotation that combines @ExtendWith(SpringExtension.class) from JUnit Jupiter with @ContextConfiguration from the Spring TestContext Framework.

This annotation will be inherited from an enclosing test class by default. See @NestedTestConfiguration for details.
