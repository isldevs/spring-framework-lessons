A recipe is not an object. Neither is a bean definition. ☕

Look inside ApplicationContext: configuration → refresh → managed beans → getBean. Then see the same context dispatch an event and run cleanup when it closes.

The Java tests check the same service reference, one handled event and cleanup. A separate lazy-bean test shows why a definition can exist without an instance.

Definitions describe. Instances do the work.
