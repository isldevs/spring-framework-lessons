## Caption and hashtags

Your class can compile perfectly and still be missing from Spring. ☕

Spring needs a registration path: an @Bean method in registered configuration, or an @Component class discovered by the configured component scan.

Scanning the wrong package leaves even an annotated class outside the container. The Java tests check both successful paths and that missing-bean case.

Give Spring a registration path. Then request the bean.
